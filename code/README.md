
## Module 1.8: Business Helper Chatbot

A rule-based chatbot for Sweet Crumbs bakery that answers
common customer questions and tracks unanswered messages.

| Intent | Keywords | Reply |
|---|---|---|
| Complaint | refund, complaint, late | Manager will help |
| Opening hours | hour, open, time | 9 AM to 10 PM |
| Prices | price, cost, how much | Cake and cupcake prices |
| Location | where, location, address | Main Boulevard, Lahore |
| Ordering | order, delivery | Business WhatsApp |
| Greeting | hi, hello, salam | Friendly greeting |
| Human support | human, agent | Connecting to a human |
| Exit | bye, exit | Goodbye and summary |
| Other questions | No match | Print a prompt for AI |
